## Upload to GitHub Pages

1. Open the repo: [fabricrules-privacy](https://github.com/polyakovamargarita/fabricrules-privacy).
2. Upload **everything inside this folder** to the **root** of that repo:

```
index.html
README.md
privacy/index.html
support/index.html
```

3. In repo **Settings → Pages**:
   - Source: Deploy from a branch
   - Branch: `main` (or `master`), folder `/ (root)`
4. Wait 1–2 minutes, then open the links above.
